# Simple Cybersecurity Lab public website

Official product information, support, and privacy policy for Simple Cybersecurity Lab by LIPAI WANG.

- Website: https://williamjiamin.github.io/simple-cybersecurity-lab-site/
- Support: https://williamjiamin.github.io/simple-cybersecurity-lab-site/support.html
- Privacy: https://williamjiamin.github.io/simple-cybersecurity-lab-site/privacy-policy.html

This public repository contains only the static website. The native app, training game, book manuscripts, signing material, and release evidence are not included here.

GitHub Pages serves the root of `main`. No build, JavaScript, analytics, external font, or package installation is needed. Keep `.nojekyll` in the publishing root.

To preview locally: `python3 -m http.server 8787 --bind 127.0.0.1`.

App downloads are not yet available. Add verified store links after release; do not present review builds as public releases.
